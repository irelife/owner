# オーナーマイページ

IREライフ株式会社のオーナー様が、収支明細をいつでもご確認いただくための画面です。

公開先： https://irelife.github.io/owner/

---

## この入れものに入っているもの

```
index.html        画面（ログイン・ホーム・入居状況・明細・修繕・火災保険・
                  問い合わせ・税理士へ送信・マイアカウント）
css/style.css     見た目
js/config.js      ★ Apps Script のURLだけ、ここに入れます
js/app.js         画面の動き
staff.html        当社用の画面（合言葉で入ります）
tests/            検査。tlogin（ログイン）／ tins（火災保険）／ tpp（送金明細）／
                  tst（入居状況）／ tacc（税理士へ送信）／ tmy（マイアカウント）／
                  tgas（ext.gs の直しかた）
docs/             引き継ぎ書・はじめの設定・PIVOT側の追加・使いかた・やること
gas/              Apps Script の控え（置きかたは gas/README.md）
```

**はじめての方は `docs/引き継ぎ書.md` をご覧ください。**
いまの状態・窓口24個・表の一覧・踏んだ落とし穴15個・残っている仕事が
すべてそこにあります。

## この入れものに入っていないもの

**オーナー様の氏名・住所・金額・明細PDFは、1件もここにありません。**

すべて Google 側（スプレッドシート・ドライブ）にあります。
この入れものは公開されているため、中身は一切置きません。

```
    オーナー様のスマートフォン
            │
            ▼
    この入れもの（GitHub Pages）……… 画面だけ
            │  入館証を付けて問い合わせ
            ▼
    Apps Script ………………………… ここで本人確認・中身の判断
            │
            ├─ スプレッドシート …… オーナー／明細／入居状況／問い合わせ
            └─ Google ドライブ …… 明細PDF
```

## PIVOT とはつながっていません

オーナー様の画面から、PIVOT や Firestore へは一切つながりません。

毎月 PIVOT2 の「オーナーメール」画面で ［マイページへ送る］ を押したときだけ、
PIVOT → マイページの向きに、そのオーナー様のぶんだけが送られます。

## 守りかた

| | |
|---|---|
| パスワード | そのまま保存しません。SHA-256（パスワード＋一人ずつ違う塩＋スクリプトプロパティの胡椒）の結果だけを持ちます |
| ログインの証 | 32文字の入館証。14日で切れます |
| 当てずっぽう | 同じIDで10分に5回まちがえると、30分お待ちいただきます |
| 明細PDF | 共有リンクにしません。Apps Script が読んで、ご本人にだけ渡します |
| ほかのオーナー様の情報 | 画面で隠すのではなく、そもそも通信に載せません |
| 登録の有無 | ログインでも再設定でも、有る／無いを答え分けません |

## 変更するとき

`js/` や `css/` を直したら、`index.html` の `?v=` を **必ず1つ上げて**ください。
上げないと、端末が前に読んだものを使い回し、直しが1台も届きません。

直したら、検査を通してください。

```
node tests/tins.cjs    火災保険（69件）
node tests/tpp.cjs     送金明細（33件）
node tests/tst.cjs     入居状況（46件）
node tests/tacc.cjs    税理士へ送信（43件）
node tests/tmy.cjs     マイアカウント（69件）
node tests/tgas.cjs    ext.gs の直しかた（37件）
```

ログインの検査は、本物のブラウザを使うので先に道具を入れます。

```
cd tests && npm install && npx playwright install chromium
node tests/tlogin.cjs   ログイン（12件）
```
