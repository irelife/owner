### 物件と部屋の分けかた（いまは画面側でやっています）

本線の `status` 窓口は `place` を1本の文字列で返します（「カルムコート東棟 201号室」）。
そのため、うしろが `…号室` の形のときだけ切り分けています。

```
カルムコート東棟 201号室  → 物件「カルムコート東棟」／部屋「201号室」
カルムコート東棟201号室    → 同じ（空白が無くても切れます）
マーベラス B101号室        → 物件「マーベラス」／部屋「B101号室」
グロリオサ 東棟            → 物件「グロリオサ 東棟」／部屋なし
                             ★空白だけで切ると「東棟」が部屋になるため、
                               「号室」の形が無いときは切りません
```

★ **`status` 窓口が `prop` と `room` を別々に返すようにすれば、
　 切り分けは不要になります。**（PIVOT2 はすでにその形で送っています。
　 GAS が `place` に1本化しているだけです）
　 その場合も画面側の直しは要りません。`prop` があればそちらを使います。

### 抜き取らなかったもの（理由つき）

| 抜き取らなかったもの | 理由 |
|---|---|
| **`pdf_url` で原本PDFを直接ダウンロード** | **共有リンクになります。**ご指示の「明細PDFは共有リンクにしません。Apps Script が読んで、ご本人にだけ渡します」に反します。本線は `pdf` 窓口が base64 を返し、画面が Blob にする形のままにしました |
| **jsPDF で画面側からPDFを作る** | **日本語が1文字も出ません。**jsPDF の既定フォント（helvetica）は CJK の字を持っていません。出すには NotoSansJP の埋め込み（字を絞っても数百KB）が必要です。本線のPDFは Apps Script が作るので、この問題がありません |
| **金額を `\` で書く書きかた** | React 版の `` `\\${…}` `` はテンプレート文字列でバックスラッシュ1つになり、**`¥1,284,000` ではなく `\1,284,000` と出ます** |
| **CSV で金額まで引用符で囲む** | Excel が文字として読むことがあります。本線は**文字は囲み、数は囲みません** |
| **`.catch` を書かない読み込み** | React 版は通信が落ちても「データがありません」と出ます。**オーナー様には「まだ無い」と読めますが、実際は繋がっていません。**本線は失敗した理由を画面に出します |
| **読めない月を `0` として並べる** | `0` が2つ以上あると並びが不定になり、**黙って違う月が先頭に来ます。**本線は `null` を返し、読めない月があれば並べ替えません |
| **選んだ月のカードが閉じたまま** | React 版は `expanded` に最新の `id` しか入れないため、月を選ぶと金額だけ出て、もう一度押さないと内わけが見えません。本線は選んだら開いて出ます |
| **改ページの無いPDF** | React 版は `y` を足し続けるだけで `addPage()` がなく、A4 の下端を越えたぶんが静かに消えます |

### まだ抜き取っていない仕様（Apps Script 側の足しが必要です）

**`Statement.message`（その月の、当社からのひとこと）。**
Base44 版は明細1件ごとに `message` を持ち、PDFの末尾に載せています。

本線で同じことをするには、`明細` シートに `備考` の列を足し、
`papers` が `message` を返すようにする必要があります。
**画面側だけ先に作っても、何も出ません。**ですので、いまは入れていません。

★ 入れると良い場面：「10月は原状回復の精算があるため、いつもより少なくなります」
　 といったご説明を、明細のところに残せます。いまは「お問い合わせ」で
　 別に書くしかありません。
