## 6. 踏んだ落とし穴

| | 何が起きたか | なぜか／どう直したか |
|---|---|---|
| ① | Apps Script への通信が、すべて失敗した | `Content-Type: application/json` にすると、ブラウザが先に「許可を聞く通信」を投げます。Apps Script はそれに答えられません。**`text/plain` にします**（`js/app.js` 12〜16行目の但し書き） |
| ② | 直したのに、1台も新しくならない | `index.html` の `?v=` を上げていませんでした。**`js/` `css/` を直したら必ず1つ上げます** |
| ③ | 公開リポジトリに、オーナー様の実名とメールが入っていた | 2026/9/17 に取り除きました（オーナー37件・メール12件・お名前11名）。`pivot2/js/ownermail.js` 7〜14行目に経緯が残っています。**`pivot2` `pivot3` は公開です** |
| ④ | ボタンが2回目から「送信中…」のままになった | `busy()` が2回目の呼び出しで「送信中…」を元の字として覚えていました。`dataset.busy` で二重呼びを防いでいます（`js/app.js` 46〜62行目） |
| ⑤ | パスワードを見せたまま、次の画面へ行けた | 画面を移るときに必ず隠しに戻します（`eyeReset()`。`show()` から呼びます） |
| ⑥ | 入居状況の札に、日付が出ていた | サーバーが返す `tag` は解約予定のとき日付です。札は「解約予定」と書き、日付は下の行に回しました（`mvRows()`） |
| ⑦ | マージ済みの PR に push しても、入らなかった | GitHub の PR 画面は、閉じたあとも開いていたときとほぼ同じ見た目で残ります。**新しい枝と新しい PR を作ります** |
| ⑧ | **PIVOT2 の［マイページへ送る］が、通信を1回も始めなかった** | `pivot2/js/ownermail.js` は全体が囲い（IIFE）の中にあり、`detail`（仕分け結果）と `makeOwnerPdfBase64` は**外から名前で呼べません**。`window.RENT` の一覧にも入っていませんでした。`tomypage.js` は外から `detail` を読もうとして毎回 `null` になり、「送るものがありません」で止まっていました。→ `window.RENT` に読み取り口を2つ足し、`tomypage.js` は読めなかったときに `localStorage` から読むようにしました |
| ⑨ | 火災保険の一覧に、CSS が1行も当たっていなかった | `.item` `.row-btn` `.x` `.t` `.s` が `css/style.css` に無く、素の文字が並んでいました。2026/9/22 の作り替えで直しました（ホームの物件一覧も同じ理由で直しました） |

**サーバーの窓口は1つも増やしていません。** `insList` が返す `prop`（物件名）で
まとめているだけです。Apps Script の貼り直し・デプロイのやり直しは要りません。

### 物件名のまとめかた

`insNorm()` で、こうそろえてから見比べます。

```
カルムコート 東棟  ┐
カルムコート　東棟  ├→ すべて同じ物件として、1つの箱に入ります
ｶﾙﾑｺｰﾄ東棟        ┘
カルムコート西棟   → 別の物件（東と西は分けます）
```

### 満期日

```
読めるもの： 2028-03-31 ／ 2028/3/31 ／ 2028年3月31日 ／ 20280331 ／ 2028年3月
読まないもの： 令和10年3月31日 ／ 来年の3月 ／ 満期は代理店に確認中
```

**読めないものは、推測しません。**「満期日が未記入」の札を出し、
書かれた文字はそのまま画面に出します（消しません）。

### まだできないこと

- **預けたものの「直し」**（満期日だけ訂正・証券の差し替え）。
  いまは消して入れ直していただく形です。Apps Script に `insEdit` を足せば作れます
- **満期のお知らせメール**。画面で見えるだけです

### 直すときに気をつけること

**入力欄（`#in-form-host`）を `#in-boxes` の中に入れないでください。**
一覧を描き直すたびに `innerHTML` で作り直すため、中に入れると
入力欄ごと消え、`#f-ins` `#in-go` も一緒に無くなって二度と送れなくなります。
`index.html` の但し書きにも書いてあります。
