## 2. 全体の作り

```
   オーナー様のスマートフォン／パソコン
              │
              ▼
   https://irelife.github.io/owner/        ← GitHub Pages（公開）
   　index.html / css/style.css / js/app.js   画面だけ。中身は持ちません
              │  fetch（POST・JSON）
              ▼
   Apps Script ウェブアプリ                 ← ★URLは社外に出さない
   　コード.gs / ext.gs / paper.gs / pass.gs   判断はすべてここ
              │
      ┌───────┴────────┐
      ▼                ▼
  スプレッドシート      Google ドライブ
  「オーナーマイページ 台帳」   明細PDF・保険証券（非公開）
      ▲
      │ ［マイページへ送る］
   PIVOT2（毎月の明細作成）
```

**守りの要点**

- パスワードは保存していません。`SHA-256(パスワード + 塩 + 胡椒)` の結果だけを持ちます。台帳が漏れても、胡椒（`PEPPER`）が無ければ戻せません。
- PDFは共有リンクにしません。`apiPdf` が、**ご本人の明細に載っているIDのときだけ**中身を渡します。
- ログインに5回失敗すると30分止まります（`locked_`）。
- 「このメールは登録されていません」とは答えません。登録の有無を外から調べられないためです。

## 4. 窓口（画面が使う18個）

`js/app.js` が `auth(窓口名, {…})` で叩きます。**返る形を変えると画面が止まります。**

### ログインが要らないもの

| 窓口 | 返るもの |
|---|---|
| `login` | `{token, owner:{name,atena}, mustChange}` |
| `forgot` | `{ok:true}`（登録が無くても同じ。有無を知られないため） |
| `logout` | `{ok:true}` |

### 入館証が要るもの（`コード.gs`）

| 窓口 | 返るもの |
|---|---|
| `me` | `{owner:{name,atena}, mustChange}` |
| `changePass` | `{ok:true}` |
| `home` | `{month, total, sokinDate, pdfId, rows:[{label,amount}], moves:{newc,yotei,boshu}（件数）, props:[{name,note}]}` |
| `status` | `{month, newc/yotei/boshu:[{place,tag,detail}], message}` |
| `papers` | `{years:[{year, items:[{id,label,ym,month,total,sokinDate,rows:[{label,amount}]}]}], chart:[{ym,month,total}]}` |
| `pdf` | `{name, b64}` |

### 入館証が要るもの（`ext.gs`）

| 窓口 | 返るもの |
|---|---|
| `insList` | `{list:[{id,label,prop,maker,tel,mail,no,until,at}]}` |
| `insPut` / `insDrop` / `insFile` | 登録／削除／中身 |
| `works` | `{list:[{id,place,what,from,to,yen,offset,state,note,msgs}]}` |
| `workMsg` | 工事へのご連絡 |
| `talks` | `{list:[{id,kind,date,state,msgs:[{at,who,body}]}]}` |
| `ask` / `talkMsg` | 新しいご相談／続きのご連絡 |

### 合言葉（`ADMIN_KEY`）で入るもの

| 窓口 | 使う場所 |
|---|---|
| `push` / `putPdf` | PIVOT2 の［マイページへ送る］ |
| `stPing` / `stList` / `stReply` / `stArea` | `staff.html`（当社用） |

★ `contact` と `threads`（`コード.gs`）は、`ask`/`talks`（`ext.gs`）に置き換わって**使われていません**。

## 8. 踏んだ落とし穴（同じことを繰り返さないために）

### ① マージ済みの PR に、あとから push しても入らない

PR #2 をマージしたあと、同じ枝に2つ積んでも `main` には入りませんでした。**マージ済みの PR は終わりです。** 新しい枝を切って、新しい PR を作ってください。checkin でも同じことをしました。

### ② `?v=` を上げないと、古い画面が出る

`js/` や `css/` を直したら、`index.html` の `?v=` を**必ず1つ上げる**。いまは `?v=15`。

### ③ Apps Script は「デプロイを管理 → 鉛筆 → 新バージョン」

**「新しいデプロイ」を押すと URL が変わり、マイページが止まります。**

### ④ 行のとちゅうから選んで貼ると壊れる

`コード.gs` の353行目を、行のとちゅうから選んで貼り替えたため、次の行とくっついて構文エラーになりました。**必ず行まるごと**選んでください。

### ⑤ ブロックごと置き換えるときは、巻き添えを確かめる

`css/style.css` を範囲で置き換えたとき、あいだにあった「タイル（ホームのカード）」のきまりを**まるごと消していました**。`js/app.js` でも古い `paintChart` が後ろに残り、新しいほうを打ち消していました。**置き換えたら、消えたセレクタと関数の重複を必ず数えてください。**

### ⑥ 「2026年9月」はスプレッドシートが日付に直す

`appendRow` で入れると、日本語ロケールでは日付として保存されます。**読む側で両方うけとる**ようにしてあります（`ppKey_`）。PIVOT2 から送るときも同じことが起きます。

### ⑦ 番号を行番号から作ると、ぶつかることがある（**未修正**）

`ext.gs` の `apiAsk` は `'C' + 日付 + '-' + (最終行+1)` で番号を作ります。ふたりが同じ秒に送ると**同じ番号**になり、`msgsOf_` は番号だけで引くので、**別のオーナー様のやりとりが混ざって見えます**。直しかたは下の「9-③」。
