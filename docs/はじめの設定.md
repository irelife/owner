# はじめの設定

順番どおりに進めてください。**30分ほど**です。

★ この書類は社外に出さないでください。

---

## ① スプレッドシートを作る

1. https://sheets.new を開く
2. 名前を **`オーナーマイページ 台帳`** にする

## ② Apps Script を貼る

1. その画面の上のメニュー → **拡張機能** → **Apps Script**
2. 出てきた `コード.gs` の中身を **全部消す**
3. お渡しした **`1_コード-gs_まるごと貼る.txt`** を全部コピーして貼る
4. 💾（保存）を押す

⚠️ **チャットの画面からではなく、必ず `.txt` ファイルからコピーしてください。**
チャットは長い内容を途中で省略します。

## ③ 明細を入れるフォルダを作る

1. https://drive.google.com を開く
2. **新規** → **新しいフォルダ** → 名前を **`オーナー明細`**
3. そのフォルダを開き、**アドレス欄の最後の部分**を控える

```
https://drive.google.com/drive/folders/1AbCdEfGh...
                                       ^^^^^^^^^^^ これがフォルダID
```

## ④ 設定を入れる

Apps Script の画面で

1. 左の **⚙️ プロジェクトの設定**
2. いちばん下 **スクリプト プロパティ** → **スクリプト プロパティを追加**
3. 次の**3つ**を入れる

| 名前 | 値 |
|---|---|
| `SUPPORT` | `info@ire-life.com` |
| `SITE_URL` | `https://irelife.github.io/owner/` |
| `DRIVE_ID` | ③で控えたフォルダID |

4. **スクリプト プロパティを保存**

※ `PEPPER` と `ADMIN_KEY` は、次の⑤で自動的に作られます。

## ⑤ 表を用意する

1. Apps Script の画面の上で、関数を **`はじめの用意`** に切り替える
2. **実行** を押す
3. はじめてのときは「承認が必要です」と出ます
   → **権限を確認** → ご自身のアカウント → **詳細** → **（安全ではないページ）に移動** → **許可**
4. 「表を用意しました」と出れば成功です

スプレッドシートに、シートが6つできています。

## ⑥ ウェブアプリとして公開する

1. 右上の **デプロイ** → **新しいデプロイ**
2. ⚙️ → **ウェブアプリ**
3. 設定
   - 説明：`オーナーマイページ v1`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. **デプロイ** → 出てきた **ウェブアプリのURL** を控える

⚠️ **「全員」で公開する必要があります。**
オーナー様は Google アカウントをお持ちでないことがあるためです。
守りは Apps Script の中（パスワード・入館証）で行っています。

## ⑦ 画面にURLを入れる

1. https://github.com/irelife/owner を開く
2. `js` → `config.js` → 鉛筆マーク ✏️
3. `＊＊＊ここに…＊＊＊` の部分を、⑥で控えたURLに置き換える
4. 緑の **Commit changes**

## ⑧ 公開する（GitHub Pages）

1. https://github.com/irelife/owner の **Settings**
2. 左の **Pages**
3. **Source** を **Deploy from a branch**
4. **Branch** を **main** ／ **/ (root)** → **Save**
5. 数分待つと https://irelife.github.io/owner/ が開きます

## ⑨ 動きを確かめる

1. Apps Script の画面で、関数を **`動作テスト`** に切り替えて **実行**
2. ご自身のメールアドレス宛に、初回パスワードのメールが届きます
3. https://irelife.github.io/owner/ を開いて、そのIDとパスワードでログイン
4. パスワードの変更 → ホーム → 入居状況 → お問い合わせ を、ひととおり触る

**ここまでで第1段は完成です。**

## 困ったとき

| 症状 | 見るところ |
|---|---|
| ログインできない | `ログイン試行` シート。5回まちがえると30分待ちです |
| 明細が出ない | `明細` シートに、そのメールの行があるか |
| PDFが開かない | `ファイルID` が正しいか。ドライブでそのファイルが開けるか |
| メールが届かない | Apps Script の **実行数** で、エラーが出ていないか |

**パスワードは、当社の誰も見られません。**
お忘れのときは、オーナー様ご自身に「パスワードをお忘れの方」からお手続きいただくか、
`オーナー` シートの `初回変更` を `はい` にしたうえで、新しい初回パスワードを発行してください。
