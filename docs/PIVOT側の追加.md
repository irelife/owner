# PIVOT2 に［マイページへ送る］を足す

毎月の手順に、**最後の1押し**が増えるだけです。

```
PDFを取込 → 振り分けを確認 → メール送信 → ［マイページへ送る］ ← これ
```

★ この書類は社外に出さないでください。

---

## 足すもの

`irelife/pivot2` に **`js/tomypage.js`** を1つ足し、
`index.html` に読み込みの1行を足します。

**既存のファイルは、`index.html` の1行以外どこも触りません。**

---

## ① `js/tomypage.js` を新しく作る

お渡しした **`2_tomypage-js_新しく作る.txt`** を、そのまま
`irelife/pivot2` の `js/tomypage.js` として作ってください。

**GitHub の画面から：**

1. https://github.com/irelife/pivot2 を開く
2. **Add file** → **Create new file**
3. ファイル名の欄に `js/tomypage.js` と入れる
4. `.txt` の中身を全部コピーして貼る
5. 緑の **Commit changes**

## ② `index.html` に1行足す

`js/ownermail.js` を読み込んでいる行の**すぐ下**に足します。

```html
<script src="js/ownermail.js?v=16"></script>
<script src="js/tomypage.js?v=1"></script>   ← これを足す
```

## ③ 合言葉を入れる

オーナーメールの画面に **［マイページへ送る］** が出ます。
はじめて押したときだけ、合言葉を聞かれます。

**Apps Script（マイページ側）の スクリプト プロパティ → `ADMIN_KEY`** の値です。

⚠️ この合言葉は、社外に出さないでください。
⚠️ `pivot2` は公開リポジトリです。**コードにも `config.js` にも書きません。**
　　押したときに聞いて、その端末の中だけに覚えます。

---

## 送られるもの

そのオーナー様の**ご自身のぶんだけ**です。

| | |
|---|---|
| オーナー名・宛名・メール | オーナー一覧から |
| 対象月 | 明細から |
| 送金額・送金日 | 明細から |
| 内訳 | 明細から |
| 明細PDF | ドライブへ入れて、そのファイルIDだけ |
| 入居状況 | 明細から自動で読み取ったもの（募集中・解約予定・新規契約） |

**いま `ownermail.js` が自動で読み取っているものを、そのまま渡すだけです。**
入力の手間は1つも増えません。

---

## はじめてのオーナー様

マイページ側に居なければ、**自動でアカウントが作られ、
初回パスワードのご案内メールが届きます。**

★ お決めいただいたとおり、**まず社内2〜3名で1週間**お試しください。
オーナー様へお配りするのは、そのあとです。

**社内でお試しになるには**、オーナー一覧の「メール」を一時的に社内の方の
アドレスにして［マイページへ送る］を押すのが、いちばん簡単です。
（お試しが終わったら、元に戻してください）

---

## 送ったあとの確かめかた

| 見るところ | 何を見るか |
|---|---|
| マイページの `オーナー` シート | 行が増えているか |
| マイページの `明細` シート | その月の行があるか |
| マイページの `入居状況` シート | 募集中・解約予定・新規契約が入っているか |
| ドライブの `オーナー明細` | PDFが入っているか |

---

## 2回押してしまったら

**大丈夫です。** 同じ月のぶんは**置き換え**になります。増えません。
