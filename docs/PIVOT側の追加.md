# PIVOT2 の［マイページへ送る］

毎月の手順に、**最後の1押し**が増えるだけです。

```
PDFを取込 → 振り分けを確認 → メール送信 → ［マイページへ送る］ ← これ
```

★ この書類は社外に出さないでください。

### 届いていなかった理由（2026/9/22 に判明）

`js/ownermail.js` は**全体が囲い（IIFE）の中**にあります。
囲いの中のものは、外のファイルから名前で呼べません。

`js/tomypage.js` は囲いの外から `detail`（明細の仕分け結果）を
読もうとしていたため、**押すと毎回 `null` になり、
「送るものがありません」で止まっていました。通信を1回も
始めていませんでした。**

```js
var list;
try{ list = detail; }catch(e){ list = null; }   ← 126行目。ここで必ず止まる
```

★ この書類には「使わせてもらうもの（ownermail.js の中にあります）」と
　 書いてありましたが、**「中にある」＝「外から使える」ではなかった**、
　 というのが正体です。

**直しは `irelife/pivot2` の PR #21 です。**
`window.RENT` に読み取り口を2つ足し、`tomypage.js` はそこから読みます。
**この PR をマージしてから、下の「試し送り」に進んでください。**

## 管理キー

オーナーメールの画面に **［マイページへ送る］** が出ます。
はじめて押したときだけ、管理キーを聞かれます。

**Apps Script（マイページ側）の スクリプト プロパティ → `ADMIN_KEY`** の値です。

⚠️ この管理キーは、社外に出さないでください。
⚠️ `pivot2` は公開リポジトリです。**コードにも `config.js` にも書きません。**
　　押したときに聞いて、その端末の中だけに覚えます。

## 送られるもの

そのオーナー様の**ご自身のぶんだけ**です。

| | |
|---|---|
| オーナー名・宛名・メール | オーナー一覧から |
| 対象月 | 明細から |
| 送金額・送金日 | 明細から |
| 内訳 | 明細から |
| 明細PDF | ドライブへ入れて、そのファイルIDだけ |
| 入居状況 | 明細から自動で読み取ったもの（募集中・解約予定・新規契約） |

**いま `ownermail.js` が自動で読み取っているものを、そのまま渡すだけです。**
入力の手間は1つも増えません。
