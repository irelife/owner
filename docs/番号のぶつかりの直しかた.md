## 2. 番号のぶつかり（`apiAsk` の1か所）

### 何が起きているか

```javascript
var no = 'C' + Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyyMMdd') +
         '-' + (sh.getLastRow() + 1);
sh.appendRow([...]);
```

ふたりのオーナー様が**ほぼ同時**に送ると、どちらも「最終行」を同じ数として読み、
**同じ番号**になります。`やりとり` シートには**メールの列がなく**、
`msgsOf_` は番号だけで引くので、**別のオーナー様のやりとりが混ざって見えます。**

★ 書き込みは大丈夫です。`apiTalkMsg` は**メールと番号の両方**で確かめています。
　 混ざるのは**読むとき**だけです。

★ `askRows_`（`row`）と `workRows_`（`r._row`）は、その行の番号を使うので
　 いま重なりません。ただし**台帳の行を手で消すと行番号がずれて、
　 あとから同じ番号ができます。** 予防として同じ形に直しておきます。

### 貼るもの ①：`ext.gs` の末尾に足す

```javascript
/* ── 重ならない番号を作る ──────────────────────
 *  いままで： 'C' + 日付 + '-' + 行
 *            → ふたりがほぼ同時に送ると、同じ番号になりました。
 *  これから： うしろに8文字を足して、重ならないようにします。
 *
 *  ★8文字なのは、検査して決めました。6文字では 31の6乗＝8.8億通り。
 *    数のうえでは足りているように見えますが、20万回引くと17件重なりました
 *    （同じ誕生日の人が見つかりやすいのと同じ理由です）。
 *    8文字なら 8520億通りで、20万回引いても重なりは0件でした。
 *
 *  ★LockService は使いません。appendRow は行を取り合わないので、
 *    番号が重ならなくなれば、それで足ります。
 *    足すと、送信のたびに待ち時間が増えるだけです。
 *
 *  ★すでに入っている番号は、そのままで大丈夫です。
 *    形が変わるだけで、古い番号も今までどおり引けます。 */
function newNo_(prefix, n){
  var d = Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyyMMdd');
  return prefix + d + '-' + (n || 0) + '-' + noRand_(8);
}

/* 重ならないための文字。
 * ★ 0 O 1 I l は入れません。お電話でお伝えするときに聞き分けられないためです。 */
function noRand_(n){
  var C = 'ABCDEFGHJKMNPQRSTUVWXYZ23456789';
  var s = '';
  for(var i = 0; i < n; i++){
    s += C.charAt(Math.floor(Math.random() * C.length));
  }
  return s;
}
```

★ 名前を `rand_` ではなく **`noRand_`** にしてあります。
　 `pass.gs` に `rand_` があるかもしれず、同じ名前の関数が2つあると
　 **あとに書いたほうだけが動く**ためです。探す手間をなくすため、
　 はじめから重ならない名前にしました。

### 貼るもの ②：3か所を差し替える

**`apiAsk` の中**

/* 直す前 */

## 3. `stReply` ── お知らせ先を、画面から受け取らない

### いま

```javascript
if(req.mail){
  MailApp.sendEmail({ to: String(req.mail), … });
}
```

`req.mail` を**そのまま**使っています。当社用の画面が送ってくる値なので
ふだんは正しいのですが、担当者が一覧で選び間違えると、
**別のオーナー様に「お返事を入れました」**が届きます。

### 直しかた ── 1つ貼って、3行を置き換えます

★ 関数をまるごと差し替える形にしていましたが、**やめました。**
　 貼る場所を目で探す作業は間違えやすく、`function stArea` を
　 消してしまう危険があるためです。2章と同じ「1行ずつの置換」にします。

**(1) `ext.gs` の末尾に、これを貼る**

```javascript
/* その番号のオーナー様のメールアドレスを、台帳から引きます。
 * ★お知らせメールの宛先を、画面から受け取らないようにするためです。
 *   担当者が一覧で選び間違えると、別のオーナー様に
 *   「お返事を入れました」が届いてしまいます。
 * ★見つからなければ空を返します。当てずっぽうで送りません。 */
function mailOfNo_(id){
  var k = String(id == null ? '' : id).trim();
  if(!k) return '';
  var to = '';
  if(k.charAt(0) === 'C'){
    askRows_().forEach(function(x){
      if(String(x.no).trim() === k) to = String(x.mail || '');
    });
  }else{
    workRows_().forEach(function(r){
      if(String(r['番号']).trim() === k) to = String(r['メール'] || '');
    });
  }
  return to.trim();
}
```

**(2) 3行を置き換える**（`Ctrl`＋`H`。どれも `1 / 1 件` です）

| | 探す | 置き換える |
|---|---|---|
| ① | `addMsg_(id, '当社', body);` | 下の3行 |
| ② | `if(req.mail){` | `if(to){` |
| ③ | `to      : String(req.mail),` | `to      : to,` |

①の置き換えは、この3行です。

```
  var to = mailOfNo_(id);
  if(!to) return ng_('その番号のオーナー様が、台帳に見つかりませんでした。');
  addMsg_(id, '当社', body);
```

★ ①で**順番も変わります。台帳に番号が見つからなければ、やりとりにも書き込みません。**
　 いまは先に書き込むので、番号を打ち間違えると
　 **誰のものでもない発言**が `やりとり` シートに残ります。

★ `staff.html` は直さなくて構いません。`req.mail` を送っても無視されるだけです。

### 直したあとの `stReply`（控え。貼る必要はありません）

```javascript
function stReply(req){
  var id   = String(req.id || '');
  var body = String(req.body || '').slice(0, 4000);
  if(!id || !body.trim()) return ng_('番号と本文が要ります。');

  var to = mailOfNo_(id);
  if(!to) return ng_('その番号のオーナー様が、台帳に見つかりませんでした。');
  addMsg_(id, '当社', body);

  /* お問い合わせなら、状況を「回答済み」にします */
  if(id.charAt(0) === 'C'){
    var a = askRows_().filter(function(x){ return x.no === id; })[0];
    if(a) askSheet_().getRange(a._row, 5).setValue('回答済み');
  }

  /* オーナー様にも、お知らせのメールを送ります */
  if(to){
    try{
      MailApp.sendEmail({
        to      : to,
        replyTo : prop_('SUPPORT'),
        subject : 'オーナーマイページに、お返事を入れました（IREライフ株式会社）',
        body    : 'いつも大変お世話になっております。IREライフ株式会社でございます。\n\n' +
                  'マイページに、お返事を入れました。下記よりご確認くださいませ。\n\n' +
                  '　' + prop_('SITE_URL') + '\n\n' +
                  '─────────────────\nIREライフ株式会社\n' +
                  prop_('SUPPORT') + '\n─────────────────'
      });
    }catch(err){ log_('stReply mail', err); }
  }
  return { ok:true };
}
```

★ `if(to){` は、①で必ず中身があることが確かめられているので、いつも通ります。
　 それでも残してあるのは、**置き換えを3行だけに抑えるため**です。

## 4. 小さいもの（急ぎません）

| | 何 | どうなるか |
|---|---|---|
| 1 | `apiInsPut` の `INS_MAX` の数え | ほぼ同時に2件上げると、12件の上限を13件まで超えられます。害は小さいです |
| 2 | `やりとり` にメールの列がない | ご本人確認は「番号 → 問い合わせ・工事 → メール」とたどっています。列を足せばもっと確かになりますが、表の形が変わり、すでに入っているぶんは空のままになります |
| 3 | `msgsOf_` が毎回 `やりとり` を全部読む | 数千件になると、返信のたびに1〜2秒かかります。`TextFinder` に変えれば速くなります |

## 5. ★置換するときの注意（ここで1度つまずきました）

`Ctrl`＋`F` や `Ctrl`＋`H` を押す前に、**コードの文字の上を1回クリック**してください。

クリックせずに押すと、**Chrome の検索**が開きます。見分けかた：

| | 出る場所 | 見た目 |
|---|---|---|
| **Apps Script の検索**（これを使います） | コードのすぐ上 | `Aa` `ab` `.*` のボタンが付いている |
| **Chrome の検索**（これではありません） | ブラウザのいちばん上 | `∧` `∨` `×` だけ。**関数名を入れても `0/0` になります** |

Chrome の検索は、**画面に映っている文字しか探しません。** Apps Script は
画面外の行を描いていないので、`function stReply` を入れても `0/0` になります。
