# `ext.gs` 番号のぶつかりの直しかた

作成：2026年9月22日／対象：`ext.gs`（オーナーマイページの Apps Script）
急ぎ度：**いちばん高い。オーナー様の情報が混ざる恐れがあります。**

---

## 1. 何が起きているか

お問い合わせと工事は、**番号**で `やりとり` シートに結びついています。

```
問い合わせ … 日時／メール／用件／内容／状況／番号
工事      … 番号／メール／物件／部屋／…
やりとり   … 番号／日時／差出／本文      ← ★メールの列がありません
```

`apiAsk` は番号をこう作っています。

```
'C' + 日付 + '-' + (最終行 + 1)      例）C20260922-2
```

ふたりのオーナー様が**同じ日に、ほぼ同時**に送ると、
どちらも「最終行」を同じ数として読み、**同じ番号**になります。

`やりとり` にメールの列がないため、やりとりは**番号だけ**で引きます。
番号が同じなら、**別のオーナー様のやりとりが混ざって表示されます。**

もう1つあります。番号が `C20260922-2` のように**言い当てられる形**です。
`talkMsg`（やりとりに送る）が番号だけを見ているなら、
番号を言い当てた方が、**他のオーナー様のやりとりに書き込めます。**

---

## 2. 直す考えかた

| | すること | これで何が止まるか |
|---|---|---|
| ① | 番号のうしろに、重ならない8文字を足す | **混ざって見える**のが止まります |
| ② | やりとりに送る前に、その番号が**本当にご本人のもの**か確かめる | **他の方の所へ書き込める**のが止まります |

★ **①だけでは足りません。** 番号を当てにくくするのは、鍵をかけたことにはなりません。
　 **②が本当の鍵です。**

★ **すでに入っている番号は、そのままで大丈夫です。** 形が変わるだけで、
　 古い番号も今までどおり引けます。表の作り直しは要りません。

## 3. 貼るもの

### ① `ext.gs` の末尾に、この2つを足す（新規・そのまま貼れます）

```javascript
/* ── 重ならない番号を作る ──────────────────────
 *  いままで： 'C' + 日付 + '-' + (最終行 + 1)
 *            → ふたりが同じ日にほぼ同時に送ると、同じ番号になりました。
 *  これから： うしろに8文字を足して、重ならないようにします。
 *  ★8文字なのは、検査して決めました。6文字では 31の6乗＝8.8億通り。
 *    数のうえでは足りているように見えますが、20万回引くと17件重なりました
 *    （同じ誕生日の人が見つかりやすいのと同じ理由です）。
 *    8文字なら 8520億通りで、20万回引いても重なりは0件でした。
 *  ★ LockService は使いません。appendRow は行を取り合わないので、
 *    番号が重ならなくなれば、それで足ります。
 *    足すと、送信のたびに待ち時間が増えるだけです。 */
function newNo_(prefix, sheet) {
  var d = Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyyMMdd');
  var n = sheet ? (sheet.getLastRow() + 1) : 0;
  return prefix + d + '-' + n + '-' + rand_(8);
}

/* 重ならないための文字。
 * ★ 0 O 1 I l は入れません。お電話でお伝えするときに聞き分けられないためです。 */
function rand_(n) {
  var C = 'ABCDEFGHJKMNPQRSTUVWXYZ23456789';
  var s = '';
  for (var i = 0; i < n; i++) {
    s += C.charAt(Math.floor(Math.random() * C.length));
  }
  return s;
}
```

★ `rand_(8)` の **8** は変えないでください。6にすると重なります（上のコメント）。

★ `rand_` が**すでに `ext.gs` か `pass.gs` にある**ときは、足さないでください。
　 同じ名前の関数が2つあると、**あとに書いたほうだけが動きます。**
　 先に `Ctrl` ＋ `F` で `function rand_` を探してください。

### ② 番号を作っているところを差し替える

`Ctrl` ＋ `F` で **`'C' +`** と **`'W' +`** を探してください。
だいたいこういう形をしています。

```javascript
/* 直す前 */
var no = 'C' + Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyyMMdd')
             + '-' + (sh.getLastRow() + 1);

/* 直した後 */
var no = newNo_('C', sh);
```

`apiAsk`（お問い合わせ）・`askRows_`・`workRows_` の3か所です。
**`'W'` で始まるもの（工事）は `newNo_('W', sh)`** にしてください。

### ③ やりとりに送る前に、ご本人のものか確かめる（★これが本当の鍵）

`ext.gs` の末尾に、これも足します。

```javascript
/* その番号が、本当にこのオーナー様のものか確かめます。
 * ★これが無いと、番号を言い当てた方が、他のオーナー様の
 *   やりとりに書き込めます。番号を当てにくくするだけでは足りません。 */
function ownNo_(mail, no) {
  var m = String(mail == null ? '' : mail).trim().toLowerCase();
  var k = String(no   == null ? '' : no).trim();
  if (!m || !k) return false;

  var ss  = SpreadsheetApp.getActive();
  var see = function (name, colNo, colMail) {
    var sh = ss.getSheetByName(name);
    if (!sh || sh.getLastRow() < 2) return false;
    var v = sh.getRange(2, 1, sh.getLastRow() - 1, sh.getLastColumn()).getValues();
    for (var i = 0; i < v.length; i++) {
      if (String(v[i][colNo]).trim() === k &&
          String(v[i][colMail]).trim().toLowerCase() === m) return true;
    }
    return false;
  };

  /* 列の場所（0から数えます）
   *   問い合わせ … 日時0／メール1／用件2／内容3／状況4／番号5
   *   工事      … 番号0／メール1／… */
  return see('問い合わせ', 5, 1) || see('工事', 0, 1);
}
```

そして `talkMsg` と `workMsg` の**いちばん最初**に、この3行を入れます。

```javascript
if (!ownNo_(mail, id)) {
  return { ok: false, error: 'notfound' };
}
```

★ `mail` の変数名は、その関数が使っている名前に合わせてください
　 （`o.mail`／`owner.email` などになっているかもしれません）。
★ **「ありません」と返します。**「あなたのものではありません」とは返しません。
　 番号が存在するかどうかを教えないためです。
★ シート名は `'問い合わせ'` `'工事'` を直書きしています。
　 `SH.ASK` のような決めごとが `ext.gs` にあるなら、そちらに合わせてください。

## 4. 直したあとの確かめかた

1. Apps Script で **保存**
2. **［デプロイを管理］→ 鉛筆 → 新バージョン**
   　★［新しいデプロイ］は押さないでください。URL が変わってアプリが止まります。
3. マイページの［お問い合わせ］から1件送る
4. `問い合わせ` シートの **番号** の列を見る
   　→ `C20260922-7-K4M9QXBT` のように、うしろに8文字が付いていれば直っています
5. そのお問い合わせを開いて、返信を1件送る
   　→ 今までどおり吹き出しが並べば、古い番号も引けています
6. **古い番号のお問い合わせも開いてみる**
   　→ 中身が出れば、すでに入っている番号もそのまま使えています

## 6. これでも残ること

`やりとり` シートに**メールの列がありません**。②の確かめは
「番号 → 問い合わせ・工事 → メール」とたどっています。

もっと確かにするなら、`やりとり` に **メール** の列を足し、
書くときに入れて、読むときに絞ります。ただし

- 表の形が変わります
- すでに入っているやりとりは、メールの欄が空のままになります

ので、**②を入れたうえで、あとから足すかをご判断ください。**
②が入っていれば、いま起きている実害は止まります。
