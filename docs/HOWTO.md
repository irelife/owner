## 原状回復・修繕を、オーナー様に見せる

台帳の **`工事`** シートに、1行ずつ入れるだけです。

| 列 | 入れるもの | 例 |
|---|---|---|
| 番号 | **空のままで構いません** | （自動で入ります） |
| メール | そのオーナー様のメール | `owner@example.jp` |
| 物件 | 物件名 | `カルムコート東棟` |
| 部屋 | 部屋番号 | `207号室` |
| 内容 | 何をしたか | `原状回復（クロス張替・ハウスクリーニング）` |
| 着手日 | 始めた日 | `2026/9/3` |
| 完了日 | 終わった日（途中なら空） | `2026/9/12` |
| 金額 | 円（まだなら空） | `86400` |
| 相殺予定 | いつのご送金から引くか | `2026年10月のご送金` |
| 状況 | 下の5つから1つ | `完了` |
| 備考 | 補足（任意） | `たばこのヤニによる変色ぶんを含みます` |

**状況に入れる言葉**

```
見積中 ／ 着手待ち ／ 工事中 ／ 完了 ／ 精算済
```

※ `完了` と `精算済` は緑、それ以外は黄色で出ます。
※ **金額が空なら「費用」の行はオーナー様に出ません。**まだ決まっていないときは空のままで結構です。

## ★ 当社用の画面（おすすめ）

**PIVOT2 →［オーナーメール］→［オーナー様とのやりとり］**

```
https://irelife.github.io/pivot2/
```

★ **2026/9/23 に、PIVOT2 に一本化しました。**
　 以前あった `staff.html`（マイページ側）は取り下げました。
　 ［マイページへ送る］と同じ管理キーを使うので、入れ直しは要りません。

**はじめて押したときだけ、管理キー（`ADMIN_KEY`）をご入力ください。**
その端末に保存するので、次からは要りません。

- **お返事がまだのもの**が上に並びます
- **支社ごと**に分けて見られます（すべて／福山／倉敷・総社／岡山／支社がまだ）
- そのまま**返信**できます。オーナー様の画面に吹き出しで出ます
- **その方の支社を、その場で決められます**（ここが振り分けの元になります）
- いちばん下に、いまの**届け先**が出ます（未設定なら SUPPORT に届く旨も）

★ この画面は**社内用**です。URLを外に出さないでください。
　 管理キーを知らないと、1件も読めない作りです。

## オーナー様からの連絡に返す

オーナー様が「この工事について連絡する」から送ると、

1. `やりとり` シートに1行増えます（差出＝オーナー）
2. `SUPPORT` のアドレスにメールが飛びます

**お返事のしかたは2つあります。**

| やりかた | どうなるか |
|---|---|
| **当社用の画面から返す** | **マイページの画面に出ます**（いちばん楽） |
| `やりとり` シートに1行足す<br>番号＝同じ番号／差出＝`当社`／本文＝お返事 | 同上。画面が使えないときに |
| 届いたメールにそのまま返信 | オーナー様のメールに直接届きます。画面には出ません |

画面に残したほうが、あとから見返せます。

## 火災保険の証券

**オーナー様ご自身が入れます。**当社の手間はありません。

- 写真でも PDF でも構いません（8MBまで、1人12件まで）
- 入ると `保険` シートに1行増え、`SUPPORT` にお知らせが飛びます
- 実物はドライブの `オーナー明細` フォルダに入ります
- **共有リンクにはしません。**Apps Script が読んで、ご本人にだけ渡します
- オーナー様ご自身で消すこともできます

**入れていただく項目**

```
物件 ★必須 ／ 証券の写し ★必須
保険会社 ／ 保険会社の連絡先 ／ 保険会社のメールアドレス ／ 証券番号 ／ 満期日
```

### 2026年9月22日から、画面が変わりました

| | 改良前 | 改良後 |
|---|---|---|
| 並び | 1証券＝1行のべた並び | **1物件＝1つの箱** |
| 足しかた | 入力欄が1組だけ | ［＋ 別の物件を追加する］／［＋ この物件に証券を追加する］ |
| 物件 | **任意**（空のまま預けられていました） | **必須。**明細から分かる物件名から選びます |
| 満期日 | 文字 | **日付。**満期の近い箱が上に来ます |

**当社の手順は何も変わりません。** `保険` シートの見かたも同じです。

### 満期日の見かた

新しい画面は **`2028-03-31`** の形で入ります。
前に文字で入れられたぶん（`2028年3月31日`）も、そのまま画面に出ます。
**シートに両方の形が混ざっていても、問題ありません。**

`保険` シートを満期の近い順に並べたいときは、`2028-03-31` の形のほうが
そのまま並びます。古い書きかたのぶんは、お手数ですが手で直してください。

### 物件名が空の行

改良前は物件が任意だったため、**空のまま預けられた行**があるかもしれません。
オーナー様の画面では「物件名の入っていないもの」という箱に入り、
「物件名を入れて預け直してください」とご案内が出ます。

当社から直すこともできます。`保険` シートの `物件` に物件名を書けば、
次にオーナー様が画面を開いたときから、その物件の箱に入ります。

### 列のこと

※ **「連絡先」の列は、表のいちばん右**にあります（あとから足したためです）。
　 列の並びは見た目だけの話で、中身は名前で読んでいます。

## 表が見当たらないとき

`保険` `工事` `やりとり` の3つは、**はじめて使われたときに自動でできます**。

先に作っておきたいときは、Apps Script で **`追加の表を用意する`** を実行してください。
