# 当社側の使いかた（原状回復・修繕／火災保険）

2026年9月19日 追加

## 原状回復・修繕を、オーナー様に見せる

台帳の **`工事`** シートに、1行ずつ入れるだけです。

| 列 | 入れるもの | 例 |
|---|---|---|
| 番号 | **空のままで構いません** | （自動で入ります） |
| メール | そのオーナー様のメール | `owner@example.jp` |
| 物件 | 物件名 | `カルムコート東棟` |
| 部屋 | 部屋番号 | `207号室` |
| 内容 | 何をしたか | `原状回復（クロス張替・ハウスクリーニング）` |
| 着手日 | 始めた日 | `2026/9/3` |
| 完了日 | 終わった日（途中なら空） | `2026/9/12` |
| 金額 | 円（まだなら空） | `86400` |
| 相殺予定 | いつのご送金から引くか | `2026年10月のご送金` |
| 状況 | 下の5つから1つ | `完了` |
| 備考 | 補足（任意） | `たばこのヤニによる変色ぶんを含みます` |

**状況に入れる言葉**

```
見積中 ／ 着手待ち ／ 工事中 ／ 完了 ／ 精算済
```

※ `完了` と `精算済` は緑、それ以外は黄色で出ます。
※ **金額が空なら「費用」の行はオーナー様に出ません。**まだ決まっていないときは空のままで結構です。

## オーナー様からの連絡に返す

オーナー様が「この工事について連絡する」から送ると、

1. `やりとり` シートに1行増えます（差出＝オーナー）
2. `SUPPORT` のアドレスにメールが飛びます

**お返事のしかたは2つあります。**

| やりかた | どうなるか |
|---|---|
| **`やりとり` シートに1行足す**<br>番号＝同じ番号／差出＝`当社`／本文＝お返事 | **マイページの画面に出ます**（おすすめ） |
| 届いたメールにそのまま返信 | オーナー様のメールに直接届きます。画面には出ません |

画面に残したほうが、あとから見返せます。

## 火災保険の証券

**オーナー様ご自身が入れます。**当社の手間はありません。

- 写真でも PDF でも構いません（8MBまで、1人12件まで）
- 入ると `保険` シートに1行増え、`SUPPORT` にお知らせが飛びます
- 実物はドライブの `オーナー明細` フォルダに入ります
- **共有リンクにはしません。**Apps Script が読んで、ご本人にだけ渡します
- オーナー様ご自身で消すこともできます

**入れていただく項目**（写し以外はすべて任意）

```
物件 ／ 保険会社 ／ 保険会社の連絡先 ／ 証券番号 ／ 満期日 ／ 証券の写し
```

※ **「連絡先」の列は、表のいちばん右**にあります（あとから足したためです）。
　 列の並びは見た目だけの話で、中身は名前で読んでいます。

---

## 表が見当たらないとき

`保険` `工事` `やりとり` の3つは、**はじめて使われたときに自動でできます**。

先に作っておきたいときは、Apps Script で **`追加の表を用意する`** を実行してください。
