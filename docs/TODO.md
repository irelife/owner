## 1. 支社ごとの問い合わせ先メール　★未設定（2026/9/19 に後日と決定）

### 決まっていること

オーナー様がマイページの「お問い合わせ」から送ったものを、
**その方の支社の担当者だけ**に届けます。返信すれば、オーナー様に直接返ります。

| スクリプト プロパティ | 届け先 |
|---|---|
| `MAIL_FUKUYAMA` | 福山 |
| `MAIL_KURASHIKI` | 倉敷・総社 |
| `MAIL_OKAYAMA` | 岡山 |
| `SUPPORT` | 上のどれにも当てはまらないときの受け皿 |

★ いまは `SUPPORT` だけ入っています。3つは空のままです。
　 **プロパティを足すだけで効きます。貼り直しもデプロイのやり直しも要りません。**

### 支社の決めかた（お決めいただいたとおり）

**住所で振り分けます。** PIVOT が物件の住所（`addr`）を持っているので、
物件名→支社の表を作る必要はありません。

```
PIVOT で［マイページへ送る］を押す
   ↓  そのオーナー様の物件の住所を見る
   倉敷市老松町・玉島乙島 → 福山   ← ★いちばん先に見ます
   岡山市                → 岡山
   倉敷市・総社市         → 倉敷
   福山市                → 福山
   ↓  支社をつけて送る
オーナー表の「支社」に入る
   ↓
問い合わせが、その支社のアドレスだけに届く
```

★ 並び順に意味があります。老松町・玉島乙島を先に見ないと、
　 どちらも倉敷市なので倉敷へ流れます。

**複数の支社に物件をお持ちのオーナー様は、物件の多いほうの支社に寄せます。**

### 実装する場所（3か所）

1. `2_tomypage-js`（PIVOT側・新規ファイル）
   　送る前に、そのオーナー様の物件の住所から支社を決めて `area` に入れる
2. `コード.gs` の `HEAD[SH.OWNER]` に `支社` を足す
   　`apiPush` が `o.area` を書き込む
3. `コード.gs` の `apiContact`
   　`prop_('SUPPORT')` → その方の支社のアドレス（無ければ `SUPPORT`）

**⑩（PIVOT2に［マイページへ送る］を足す）と一緒に入れます。**
先にやると、送る側と受ける側がちぐはぐになります。

### 決めていただくこと

- 福山・倉敷・岡山の、**それぞれの問い合わせ先アドレス**
- `SUPPORT`（受け皿）を、いまの `info@ire-life.com` のままにするか
