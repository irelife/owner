# このフォルダに Apps Script は置きません

2026年9月22日

`irelife/owner` は**公開リポジトリ**です（確認しました）。
`ext.gs` の先頭には、こう書かれています。

> ★社外に出さないでください。

ですので、**`コード.gs` `ext.gs` `paper.gs` `pass.gs` をここに置くことはできません。**

引き継ぎ書7章にあった「Apps Script の4本を `gas/` に控える」という宿題は、
**取り下げました。** 私が repository の公開・非公開を確かめずに書いたものでした。

---

## 控えを取るなら

| | やりかた | ひとこと |
|---|---|---|
| 1 | `irelife/owner` を**非公開**にする | GitHub Pages は、非公開リポジトリからの配信に Pro 以上が必要です。いまの配布計画では選びにくいです |
| 2 | **`gas` 用の非公開リポジトリ**を1つ作る | 履歴が残り、差分も見られます。いちばん確かです |
| 3 | **Google の共有ドライブ**に置く | いちばん手軽です。履歴は残りませんが、「どこにあるか分からない」は解決します |

**3 → 2** の順でおすすめします。まず場所を決めるだけでも、
「Apps Script の中身がどこにも無い」状態は終わります。
