## いま、どうなっているか

このアプリのいちばん大事な部分——**本人確認・パスワードの扱い・
明細PDFの受け渡し・24個の窓口**——は、Apps Script の中にあります。

```
コード.gs    窓口の入口・オーナー・明細・入居状況・問い合わせ
ext.gs       追加の表（保険・工事・やりとり）・当社用の画面の窓口
paper.gs     明細PDF・証券の写しの受け渡し
pass.gs      パスワード・入館証・当てずっぽう対策
```

**この4本は、どのリポジトリにも1行も入っていません。**

つまり、いまこうなっています。

| | |
|---|---|
| 履歴 | ありません。いつ・どこを・なぜ変えたのか、たどれません |
| 控え | ありません。Google の画面が唯一の原本です |
| 戻し先 | ありません。間違えて消しても、元に戻せません |
| 見比べ | できません。「前はこう動いていた」を確かめる方法がありません |

## 秘密は1行も含まれません

**胡椒（`PEPPER`）と合言葉（`ADMIN_KEY`）は、コードの中にありません。**
どちらも Apps Script の **スクリプト プロパティ**にあり、コードは
`prop_('PEPPER')` のように名前で取り出しているだけです。

ですから、この4本をここに置いても、

- パスワードは分かりません（胡椒がないと、結果を作り直せません）
- 合言葉も分かりません
- オーナー様の氏名・住所・金額も入っていません（すべて台帳の側です）

**外から読めるようになるのは、「窓口の名前と、中の作り」だけです。**

守りは「作りを隠すこと」ではなく、胡椒と合言葉と入館証で行っています。
作りが読めても入れない、という形にしてあります。

## 控えかた（10分）

Apps Script の画面から、4回コピーして貼るだけです。

1. スプレッドシート「オーナーマイページ 台帳」を開く
2. **拡張機能** → **Apps Script**
3. 左の一覧から `コード.gs` を開く
4. 中身を**全部**選んでコピー（Windows は `Ctrl+A` → `Ctrl+C`）
5. GitHub の https://github.com/irelife/owner を開く
6. **Add file** → **Create new file**
7. ファイル名の欄に `gas/コード.gs` と入れる
8. 貼る → 緑の **Commit changes**
9. `ext.gs` `paper.gs` `pass.gs` も、同じように `gas/ext.gs` のように置く

★ **枝を切って PR にしてください**（`main` へ直接 push しません）。

## 置いたあと

### 変えるときの順番

```
1. Apps Script の画面で直す
2. デプロイを管理 → 鉛筆 → 新バージョン       ← ★「新しいデプロイ」は押さない
3. 直したところを、gas/ の控えにも貼る
4. 枝を切って PR
```

⚠️ **「新しいデプロイ」を押すと URL が変わり、アプリが止まります。**
`js/config.js` の `GAS_URL` も変わってしまいます。

### 控えと原本がずれたとき

**原本は、いつも Apps Script の側です。** `gas/` は控えです。
ずれていたら、Apps Script の中身で `gas/` を上書きしてください。
逆向き（`gas/` を Apps Script に貼る）は、
**その間にデプロイされた直しを消してしまう**ので、やめてください。

## 置かないと決めるなら

それでも構いませんが、**控えは別の形で必ず残してください。**
たとえば、社内の共有ドライブに `オーナーマイページ_GAS_2026-09-22.txt` の
ように、日付を付けて置く形です。

**いま何もない**、というのがいちばん困る状態です。
